# ❤️ Love Language Quiz

A modern, interactive web application built with React and TypeScript that helps users discover their primary love language or estimate a partner's love language through a guided questionnaire.

This project was developed as part of my software development portfolio while attending the Mississippi Coding Academy. It showcases my ability to build responsive, user-friendly web applications using modern front-end technologies.

## 🌐 Live Demo

**Live Website:** https://love-language-quiz--jakristancavitt.replit.app

## 🚀 Features

- Interactive multi-step questionnaire
- Two quiz modes:
  - Discover Your Love Language
  - Guess Your Partner's Love Language
- Responsive design for desktop and mobile
- Fast and intuitive user experience
- Dynamic navigation between questions
- Instant personalized results
- Modern and clean user interface

## 💻 Running Locally

Clone the repository:

```bash
git clone https://github.com/JaKristanCavitt/Love-Language-Quiz.git
```

Navigate into the project:

```bash
cd Love-Language-Quiz
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open:

```
http://localhost:5173
```
